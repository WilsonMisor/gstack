# PREOS Risk Catalogue

The four `risk-features.part-*.json` files are the compact, lossless domain/feature index extracted from the PREOS v1.0 1,130-record generated catalogue: 52 domains and 1,130 reusable risk seeds. The production engine materializes only the project-relevant subset plus bounded context combinations; it never claims this finite catalogue is the complete universe of risks.

The full 1,130-record Atomic Risk Catalogue and 55-field records remain in the canonical PREOS documentation package. Production incidents and project context can append new risk rules without deleting historical ones.

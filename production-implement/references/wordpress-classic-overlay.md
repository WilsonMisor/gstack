# WordPress Classic Theme + Custom Plugin Overlay

When the Project Contract selects this overlay: classic theme owns presentation; custom plugin owns product/business logic; WordPress core remains the runtime. Enforce nonces, capability checks, owner/tenant/role/status checks, scoped queries, prepared SQL, REST `permission_callback`, private-file authorization and WordPress-native escaping/sanitization. Block-theme/FSE/Gutenberg-layout/page-builder prohibitions apply only to projects whose contract requires this code-first classic approach.

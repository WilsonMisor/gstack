# Domain Skill Interoperability

PREOS/gstack owns workflow, production gates, evidence, human authority, continuity and traceability. Independent domain skills own specialist implementation knowledge. Bind a domain skill by name/path/capability in `domain-skill-bindings.json`; never copy or overwrite it into gstack. Project-specific constraints (for example WordPress classic-theme rules) apply only when the Project Contract selects that domain/overlay.
